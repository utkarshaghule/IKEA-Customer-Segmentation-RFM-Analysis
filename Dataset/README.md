# Dataset

## Dataset Source

**Dataset Name:** Online Retail II

**Source:** UCI Machine Learning Repository

**Official Link:** https://archive.ics.uci.edu/dataset/502/online+retail+ii

## Dataset Description

The Online Retail II dataset contains transactional data from a UK-based online retail business between December 2009 and December 2011.

The dataset includes information related to:
- Invoice numbers
- Product stock codes
- Product descriptions
- Purchase quantities
- Invoice dates
- Unit prices
- Customer IDs
- Countries

## Dataset Usage

This dataset is used in the project for:
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Customer purchasing behaviour analysis
- Recency, Frequency and Monetary (RFM) calculations
- Customer segmentation

## Dataset Access

The complete dataset is not uploaded to this repository due to file-size limitations. It can be accessed from the original UCI source using the link above.
