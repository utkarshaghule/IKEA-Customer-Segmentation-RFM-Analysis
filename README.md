## Retail Customer Segmentation & RFM Analysis

## Project Overview
This project focuses on analyzing retail customer purchasing behavior and segmenting customers using the RFM (Recency, Frequency, Monetary) approach. It combines Python, SQL Server, and Power BI to transform raw transaction data into meaningful customer insights.

## Business Problem
Retail businesses need to understand customer purchasing patterns, identify valuable customers, and recognize customers who may need re-engagement. This project uses customer transaction data to support data-driven customer segmentation.

## Project Objectives
- Analyze customer purchasing behavior.
- Perform data cleaning and exploratory data analysis.
- Calculate Recency, Frequency, and Monetary values.
- Segment customers based on RFM metrics.
- Develop an interactive Power BI dashboard.

## Tools & Technologies
- Python
- Pandas and NumPy
- SQL Server
- Power BI
- DAX
- Microsoft Excel

## Project Workflow

1. **Data Preparation:** Clean and preprocess transaction data using Python.
2. **Exploratory Data Analysis:** Explore customer transactions and purchasing patterns.
3. **SQL Analysis:** Perform data exploration and analytical queries using SQL Server.
4. **RFM Analysis:** Calculate Recency, Frequency, and Monetary metrics.
5. **Customer Segmentation:** Group customers into segments such as Champions, Loyal, and At Risk.
6. **Dashboard Development:** Build an interactive Power BI dashboard to present analytical results.
